Task 11: Basic Data Sorting & Filtering

Overview

This project demonstrates basic data sorting and filtering using Microsoft Excel and the Sample Superstore dataset.

Objectives

- Sort sales and profit values.
- Apply single and multiple filters.
- Answer basic business questions.
- Preserve the original dataset.
- Understand the importance of data filtering.

Tools Used

- Microsoft Excel
- Sample Superstore Dataset

Key Learnings

I learned how to sort data, apply multiple filters, explore business records, and preserve raw data for accurate analysis.

Deliverables

- Filtered Excel workbook
- Five answered questions
- README documentation
